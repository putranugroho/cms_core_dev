# cms_core

Aplikasi cloning Flutter Accounting yang sudah disederhanakan untuk modul:

- Kantor
- GL / COA
- Login User
- User Access

Fondasi login aplikasi, Pref, Network, Repository, Models, Utils, Assets, dan dependency modul terkait tetap dibawa dari source accounting lama.

## Run lokal

```bash
flutter pub get
flutter run -d chrome
```

Jika folder platform belum lengkap, jalankan:

```bash
flutter create .
flutter pub get
flutter run -d chrome
```
